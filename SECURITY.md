# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0-X.X | :white_check_mark: |
| 0.1-2.0 | :x:                |

Cyberattacks such as DDoS and other attacks are sent to internal affairs agencies (police).

Global updates are released only based on information from the Forguard Telegram channel.
